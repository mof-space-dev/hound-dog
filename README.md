# HOUND DOG // INFINITE ACCEL LOOP

A generative P5.js art piece inspired by the raw, unstoppable energy of a hound dog breaking through walls, built in just 3 minutes with Gemini while listening to Elvis Presley's "Hound Dog".

## Features
- **Infinite Accel Loop:** A relentless cycle of acceleration, wall-smashing destruction, and blinding neon-flashing collisions.
- **Responsive Design:** Automatically adapts to fit mobile and desktop screens.
- **P5.js / HTML5:** Built into a single, lightweight `index.html` file using p5.js CDN.

## How to View
1. Download or clone this repository.
2. Open `index.html` in any modern web browser, or host it via GitHub Pages.
